# ABandOn HarmonyOS 平板版

这是独立的 HarmonyOS 平板载体，界面资源与 `ABandOn-iPad.swiftpm/web` 保持同一份来源，因此播放方式、工具栏、音轨菜单和 PDF 预览不会出现两套 UI。

## 主要实现

- 使用 ArkWeb `Web` 组件加载 `resources/rawfile/index.html`。
- 使用 `abandonHost.dispatch(JSON)` 与 ArkTS 交互；资料库读写、系统文件选择器、PDF/图片读取和导出保存由 `HarmonyBridge.ets` 完成。
- 文件选择器允许 `.gp/.gp3/.gp4/.gp5/.gpx/.pdf/.musicxml/.xml/.mxl/.mscz/.mscx`。
- “常用功能”行的图标按钮在纵向翻页和横向动态滚动之间切换；横向模式使用 alphaTab `Horizontal + Smooth`，可拖动播放指针顶部倒三角调整横向位置，工具栏/键盘布局变化时指针高度自动跟随谱面区域。
- 播放方式图标右侧的显示模式图标按顺序循环切换：创作功能在顶部第二行+键盘在底部、创作功能在左侧栏+键盘在底部、同时隐藏创作功能和键盘；该状态会记住。
- App 冷启动时直接显示资料库，不再先短暂显示谱面。
- 启动阶段先隐藏编辑器，资料库容器准备完成后再显示，避免闪现空白谱面；横向滚动暂停后改变指针所在小节，重新播放会从当前指针位置开始。
- 播放/暂停使用统一状态入口，播放期间不再高频扫描横向滚动位置，降低掉帧和卡顿。
- 横向播放起点按竖线真实屏幕位置反查实际小节，暂停后取消残留滚动动画，再从竖线对应的小节开始；横向位置更新频率已降低并关闭原生平滑滚动以减少掉帧。
- “编辑 → 导出”支持选择 `PDF` 或 `gp`；选择 PDF 时可多选声部并合并导出到同一个 PDF。
- “音轨”菜单只保留音轨勾选、当前编辑音轨和删除，不再提供“显示全部 / 仅显示当前”。

## 构建

用 DevEco Studio 打开本目录，配置本机签名后选择平板设备运行。建议使用 API 12 或更高版本。工程需要 `@kit.ArkWeb`、`@kit.CoreFileKit` 和 `@kit.ArkTS`。

说明：本次需求涉及的谱面播放、编辑、资料库和 PDF 预览已接入；录音入口在 HarmonyOS 使用 ArkWeb 的麦克风流与 MediaRecorder 回退，伴奏捕获和资料库存储仍复用共享 Web 逻辑。
