# ABandOn for iPad / iPhone
`ABandOn.swiftpm` 是 Swift Playgrounds / Xcode 通用的 App 工程，无第三方依赖，离线可用。

## 运行
- **在 iPad 上**：把 `ABandOn.swiftpm` 放进“文件”App → 用 Swift Playgrounds 4+ 打开 → 点 ▶ 运行（可“固定到主屏幕”）。
- **在 Mac 上**：双击 `ABandOn.swiftpm`（需 Xcode 15+）→ 选 iPad 模拟器或真机 → Run。真机需在 Signing 里选你的 Apple ID。

## 触控操作
- 轻点谱面选拍/音符；底部“键盘”面板：0–9 输入品位（快速连点两次 = 10 以上），⌫ 删除，◀▶ 移动，▲▼ 换弦，插入拍/休止/附点/撤销/重做
- 双指捏合缩放谱面；上方技巧、时值按钮已放大到触控尺寸；顶栏“键盘”按钮可收起面板
- 外接键盘时，原有快捷键（数字、方向键、空格、⌘Z/⌘O/⌘S 等）同样可用
- 通过“文件”选择器打开/保存 gp3/gp4/gp5/gpx/gp

## 资料库（新）
- 顶栏“资料库”下拉菜单（不占版面）统一管理所有谱子，与文件原来在哪无关：打开/导入/拖入的 gp、gp3-5、gpx、pdf、图片会自动复制到 **资料库/曲名/** 文件夹中
- 可自由建文件夹分类（如“练习中 / 民谣 / 指弹”），文件夹里再放各曲子的文件夹；每项的 ⋯ 菜单可重命名、移动到…、删除
- “保存”写回资料库（旧格式会另存为同名 .gp，原文件保留）；“导出”可另存一份到任意位置
- 存放位置：iPad：App 自己的 Documents/Library（无需关心位置，统一在 App 内管理）
- iPad 打开 App 即进入**启动页**：最近打开 + 资料库网格，点谱子即进；随时可点顶栏“主页”回到启动页

## 本次更新
- 调音台（顶栏“调音台”下拉）：每个音轨可静音 / 独奏 / 调音量（0–200%），另有总音量；状态在编辑、撤销后保持
- 资料库：每首曲子/文件夹可“编辑信息”（作者、调弦）；打开谱子时自动从谱中读取作者与调弦；列表可按 最近演奏 / 名称 / 添加时间 / 作者 排序
- 顶栏“乐谱信息”：修改曲名、作者，并可改调弦（预设：标准、Drop D、降半音、降全音、DADGAD、Open G、Open D，或自定义音名）
- 空格键在 App 内永远是 播放/暂停（仅文本输入框中正常输入空格）

## 方向键与录音
- 方向键：↑↓ 切换弦（谱上有高亮格子），←→ 左右移动；长按连续移动并逐渐加速；按住 Alt/Option 时跳到该弦上最近的音符
- 录音（顶栏“录音”）：连接声卡/吉他后选输入设备，看电平，点“开始录音”→ 当前音轨自动静音、其余音轨照常播放；停止后可命名保存或放弃
- 保存位置：资料库中该曲目文件夹内——`名称.wav`（伴奏+吉他混音）与 `名称 干声.wav`（仅吉他输入）；资料库里可直接点开试听
- “延迟补偿”：声卡/系统延迟导致吉他与伴奏错位时，填入毫秒数（如 30）重新录音，混音会把吉他整体提前

## 导出与移调
- 顶栏“导出”：选择 PDF（任选一个声部，内容可选 五线谱+六线谱 / 仅六线谱 / 仅五线谱）或整首 .gp；可“保存到资料库”（放进该曲目文件夹）、“保存到本地…”、“分享…”（系统分享面板，已安装微信时可直接选微信）。PDF 为 A4 图像页（不可选中文字）
- 顶栏“移调”：显示当前调，选择移调半音数（显示目标调），可整首或仅当前音轨；先识别每个拍上的和弦并算出移调后的和弦，再搜索可按的常用指法（保持低音、尽量开放弦/低把位，整首手位连贯），可选“保持原音高排布”；钢琴按音高移动，超音域自动移八度；可撤销。移调后“保存”会另存为 `曲名 (D 大调).gp`，不覆盖原曲谱；也可直接导出 PDF / GP

## 移调（更新）
- 三种方式（每个方式右上角有 ⓘ，电脑悬停 / iPad 点击可看具体方案）：**智能**（默认：吉他和弦/扫弦小节 → 和弦映射，钢琴/贝斯/solo/单音 → 平移）、**和弦映射**、**整体平移**
- 和弦映射：识别和弦 → 新调下的对应和弦 → 直接套用标准按法（开放和弦优先，其次 E 型 / A 型横按）；整体平移：按相同半音数平移，吉他重算弦品，贝斯等超音域的音自动升/降八度
- 可只移调若干小节：Shift+点击、Shift+←→ 选择多个小节（iPad 用键盘面板的“扩选小节”），或在对话框里直接填写起止小节；调号仅在所选小节内改变
- 谱首的“和弦按法”区域：移调后会换成移调后实际用到的和弦（名称与指法同谱上打出的一致），不再保留移调前的旧和弦
- 和弦标注：每个小节只标第一个和弦，以及小节内和弦转换后的第一个和弦，重复的和弦不再逐拍标注

## 钢琴伴奏 / 钢琴 Solo
- 顶栏“钢琴伴奏”：选择用来识别和弦的吉他/贝斯音轨和“主旋律”音轨，生成左右手配合的钢琴谱（新音轨，可撤销）。和弦按拍位识别；左手弹根音/五音，右手弹以三音、七音为主的和弦或琶音；主旋律忙的地方改为长音，右手保持在主旋律下方 3 个半音以上，不与它的音高相撞。每小节第一个和弦、以及和弦转换处会在谱上标出和弦名
- “钢琴 Solo”：切到钢琴音轨，选中若干小节（Shift+点击 / Shift+←→ / iPad“扩选小节”，或在对话框里填写起止小节），把这些小节的右手改写成适配该和声的即兴 Solo（强拍落在和弦音上，其余按和弦对应音阶行进），左手伴奏不变；再点一次会换一个新版本
- 钢琴伴奏/Solo 生成后会出现预览条：可试听（可选“仅听钢琴”），再选择“保留”或“放弃”
- 删除音轨：顶栏音轨旁的“删轨”按钮，或调音台里每个音轨的“删除”；可用 ⌘Z 撤销
- 调音台音量以“轨道自带音量”为 100% 基准，编辑/重新载入后会自动恢复；自动生成的钢琴默认较轻（可在生成对话框选“轻/适中/较响”）

## 界面精简（本次）
- 去掉“资料库”按钮（主页就是资料库）与“页面/横向”按钮
- 音轨切换改为下拉列表，每个音轨右侧有红色 ✕；点 ✕ 弹出确认，可选“本次不再提示 / 永久不再提示”
- 缩放：⌘/Ctrl/Option + 滚轮（或触控板捏合）平滑缩放，也可在“缩放”框里直接输入百分比，限制在 50%–150%
- macOS 版：顶部系统菜单栏新增 **主页**、**编辑**（打开/保存/导出/撤销/乐谱信息）、**创作**（钢琴伴奏/钢琴 Solo/重做）；窗口里不再重复放这些按钮
- 内录改为仅在录音时才接入音频输出；播放缓冲加大到 800ms，减少爆音

## 导入 MusicXML / MuseScore，导出 .gp，合并乐谱
- 可打开 `.musicxml` / `.xml` / `.mxl`（MusicXML）和 `.mscz` / `.mscx`（MuseScore）；打开后点“保存”会在该曲目文件夹里另存为同名 `.gp`（原文件保留），或用“导出”选 Guitar Pro 格式
- MuseScore 导入支持：多声部、多谱表（钢琴）、拍号/调号/速度、三连音、附点、延音线、反复记号；吉他等弦乐器按其调弦自动换算成弦与品；暂不支持：打击乐声部（会提示并跳过）、装饰音、力度/歌词
- “合并乐谱”（创作菜单）：把另一份乐谱（如钢琴 .gp）里选中的音轨并入当前乐谱，按小节号对齐，可设起始小节；合并后可试听，再决定保留或放弃
- 修复：移调后调号现在会同步到每个音轨（之前只改了第一个音轨）；新生成的钢琴谱沿用乐谱当前的调号

## 界面统一改版
- **顶部分层**（Mac 与 iPad 一致）：
  - macOS：系统顶部菜单栏 = **主页**（资料库）/ **编辑**（打开、保存、导出、撤销、乐谱信息）/ **创作**（钢琴伴奏、钢琴 Solo、合并乐谱、录音、移调、重做）。
  - iPad：没有系统菜单栏，所以在窗口最上方放一条**同样的三个菜单**（内容、顺序完全一致）。
  - 第一行 = 常用功能：播放/停止、速度、BPM、节拍器/预备拍/循环、音轨、调音台、缩放、创作工具位置。
  - 第二行 = 创作工具（全部符号）：时值（全/二分/四分/八分/十六分/三十二分音符、附点、休止）、技巧（击/勾弦连音弧、滑音斜线、推弦箭头、颤音波浪线、P.M. 闷音、L.R. 延音、× 死音、( ) 幽灵音、> 重音）、插入/删除拍、增/删小节。
- **创作工具位置**：第一行右侧的按钮可选 上方第二行 / 左侧栏 / 隐藏（会记住）。
- **音轨多选显示**：点音轨名展开列表，勾选要显示的音轨；点名称设为“当前编辑音轨”（编辑只作用于它；也可直接点击谱面上其他音轨的音符切换）；右侧红叉删除（带确认，可选不再提示）。“显示全部 / 仅显示当前”两个快捷按钮。
